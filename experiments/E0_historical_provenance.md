## 3. Historical Configuration
- **Dataset:** 18 subjects, 60 trials per subject, 64 Hz sampling rate.
- **EEG Channels:** `[13, 46, 43, 23, 50, 0, 52, 14]` (C5, FCz, FC6, P9, C6, Fp1, TP8, T7)
- **EEG Preprocessing:** 1-6 Hz bandpass, Z-score normalized per trial *before* windowing.
- **Audio Representation:** Gammatone envelopes (28 bands, see below).
- **Audio Normalization:** Z-score normalized per trial *before* windowing.
- **Train Window:** 5s length, 2s stride.
- **Loss:** Contrastive Margin Loss (margin=0.1).
- **Optimizer:** Adam (LR 1e-3, Weight Decay 1e-4) with AMP Scaler.
- **Validation:** 90/10 trial-level split on the 17 training subjects. Patience=10 epochs.
- **Checkpoint Selection:** Highest validation accuracy.

## 4. Evaluation Protocol & Window Provenance (Resolving the Discrepancy)
The historical discrepancy regarding the evaluation window (3s vs 10s vs 30s) is mathematically resolved by the logs:
`"5400 evaluation windows, 69.02% MatchNet LOSO accuracy"`

**Mathematical Proof:**
- 18 subjects * 60 trials = 1,080 trials.
- Trial length = ~50 seconds.
- 5,400 total windows / 1,080 trials = **exactly 5 windows per trial**.
- 5 windows * 10 seconds = 50 seconds.
- Therefore, the historical evaluation window was **exactly 10 seconds, non-overlapping**.

## 5. Audio Feature Provenance
The audio features (`gammatone_envelopes.pkl`) were generated by `data/extract_gammatone_envelopes.py` in the `EEG_Training_New` repository.

**Code Audit of `extract_gammatone_envelopes.py`:**
- **Extractor:** `scipy.signal.gammatone`
- **Filter Type:** FIR (`'fir'` is explicitly passed).
- **Filter Length:** `numtaps` is NOT specified, meaning SciPy defaults to 15ms.
- **Bands:** 28 bands, ERB-spaced from 50 Hz to 8000 Hz.
- **Envelope:** Computed via `np.abs(filtered) ** 0.6` (power compression).
- **Lowpass:** 3rd order Butterworth lowpass at 8 Hz.
- **Downsampling:** `resample_poly` to 64 Hz target.
